# Contexto del producto

## Objetivo

Crear la presencia web oficial de Diamond Publicidad.

## Objetivos iniciales

- Presentar la empresa.
- Presentar los servicios confirmados.
- Mostrar un portafolio cuando exista material aprobado.
- Facilitar el contacto.
- Generar confianza sin inventar informacion comercial.

## Posibles secciones iniciales

La siguiente es una **propuesta inicial**, no una lista confirmada del negocio:

- Inicio
- Servicios
- Portafolio
- Nosotros
- Contacto

El contenido de cada seccion queda pendiente de definicion y aprobacion.
